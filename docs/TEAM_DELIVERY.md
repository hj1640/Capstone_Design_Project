# 팀원 공유문 — 복사해서 전달할 내용

이번 작업은 기존 Expo 앱에 **개인별 구매 기록 평균**을 연결하는 변경입니다. 최신 범위는 지류 영수증과 쿠팡 주문내역 모두 지원, 사용자가 확인한 포장지 소비기한 사용입니다.

사용자가 입력한 포장지 날짜에서 실제 구매일을 뺀 일수를 계정·식품명·보관 조건별로 집계합니다. 같은 구매를 고치면 기존 기여를 교체하고, 철회하면 제거합니다. 요청 재전송·동시 수정·앱 로직 및 서버 재시작을 검사했습니다. 여러 사람이 공용 소비기한을 학습하는 기능이나 식품 안전기간의 검증을 완료한 것은 아닙니다.

앱의 연결 정보 보관, 전경 자동 재시도, 전송 상태/제외 사유/충돌 확인 화면, 서버 실행·개인 연결 코드 발급·DB 백업 도구, 기존 Expo 프로젝트의 새 APK 빌드 설정을 추가했습니다. 날짜 의미와 필터 근거는 `docs/APP_INTEGRATION_REPORT.md`에 있습니다. 임의 이상값 가중치와 최소 N명 기준은 현재 개인 평균에 적용하지 않습니다.

**GitHub 업로드만으로 기존 APK에 적용되지는 않습니다.** 별도 서버가 아직 없으므로 서버·도메인·운영 담당을 정하고, 기존 Expo projectId/package/서명 확인 후 새 APK를 만들어 실제 휴대폰에서 인수해야 합니다. 각 담당은 아직 정해지지 않았습니다.

| 담당 역할 | 할 일 | 완료 증거 |
|---|---|---|
| 코드 검토 담당 | PR 전체 변경, 평균 정의/입력 의미/호환성 확인 | 리뷰 기록 및 PC 검사 결과 |
| 서버 담당 | 서버·도메인 확보, HTTPS 배포, 영구 DB, 개인별 코드, 백업/복원 | health 응답, 재시작 및 복구 결과 |
| 앱 빌드 담당 | 기존 Expo 계정 로그인, 실제 projectId/package/서명, preview 환경 변수, 새 APK | 커밋 SHA와 새 APK 빌드 링크 |
| 시험 담당 | 실제 지류/쿠팡, 날짜 수정, 오프라인 재시작, 중복·철회, 계정 격리 | 기기/OS/결과가 적힌 인수표 |
| 데이터 담당 | 실제 상품명→표준 식품 목록과 기간 출처 제공 | 출처·버전·검증 가능한 실제 데이터 |

읽을 순서: `APP_INTEGRATION_REPORT.md` → `APP_DEPLOYMENT.md` → `benchmarks/DEPLOYMENT_RESULTS.md`. 실기기 검사는 `benchmarks/DEVICE_ACCEPTANCE_TEMPLATE.md` 사용. 실제 상품 DB·FoodKeeper 원본·휴대폰 모델 성능·공개 서비스 부하/보안 평가는 아직 남아 있습니다.

이 파일은 전달용 초안입니다. 도구로 팀원에게 메시지를 보내지는 않았습니다.
