# PR 제목
개인별 포장지 잔여일수 통계와 지류·쿠팡 등록 경로를 연결하고 0~8단계 검증 근거 정리

## 문제와 변경 결과

기존 로컬 구현은 온라인 전용 등록과 공용 평균 실험 중심이어서, 현재 요구인 지류·쿠팡 입력/포장지 날짜/개인별 평균과 달랐습니다. 정상 앱 경로에 개인 평균 화면과 서버 API를 연결하고 날짜 수정·철회가 같은 구매의 기여분을 교체/제거하도록 바꿨습니다. 평균의 의미는 `라벨 날짜 − 실제 구매일`이며 식품의 안전 기간이나 실제 소비 기간으로 취급하지 않습니다.

계정·확인 식품명·보관 조건별 count/sum을 증분 갱신합니다. 요청키/내용 해시/예상 revision/SQLite 트랜잭션으로 중복과 동시 갱신을 처리합니다. 로컬 저장과 고정 요청을 통해 응답 유실·재시작·전송 중 수정/철회를 복구합니다. 구형 v1 데이터는 보존하며 새 개인 통계에 자동 동의시키지 않습니다.

근거 없는 공용 가중치 필터는 개인 경로에서 사용하지 않습니다. 기존 정책의 입력 순서 의존 반례를 재현 가능한 검사로 남겼습니다. 날짜·보관 조건·관측 의미 검증 사유를 화면에 표시하고, 검증되지 않은 위험 색상 임계값은 달력 상태 표시로 바꿨습니다. 실제 데이터가 없는 기본 소비기한은 계속 미정입니다.

## 검증

`python scripts/verify_review.py` 결과와 환경/시간/소스 해시는 `benchmarks/REVIEW_RESULTS.md` 및 `benchmarks/review-verification.json`에 있습니다. 서버 회귀·개인 통합 HTTP·기존 모델/카탈로그 검사·타입·린트·Android JavaScript bundle을 포함합니다. 사용 자료는 명시적 합성 fixture입니다.

실제 Android UI/ML Kit 이미지/네이티브 SQLite 재시작/네이티브 모델 성능, 새 APK 빌드·설치, 운영 인증·HTTPS 배포, 실제 식품 기간 자료는 검증하지 않았습니다. JS bundle을 APK 성공으로 표현하지 않습니다.
