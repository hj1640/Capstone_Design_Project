# 7단계 합성 정책 비교

모든 숫자는 검증용 합성값이며 실제 식품 소비기한이 아니다.
정상 계정 3개(9,10,11), 다른 계정 하나가 999를 20번 제출. 최초 기준값 10.
원자료 전체를 단순 평균하면 870.0이지만, 같은 계정의 중복·이상값 처리가 필요하다.

| 실험 방법 | 최소 정상 계정 | 반복 제출 후 평균 | 집계 계정 / 정상 계정 | 내부 배포 조건 충족 | 정상 1명 철회 후 |
|---|---:|---:|---:|---|---|
| arithmetic_mean | 3 | 10.0000 | 3 / 3 | True | eligible=False |
| arithmetic_mean | 5 | 10.0000 | 3 / 3 | False | eligible=False |
| weighted_mean | 3 | 10.1666 | 4 / 3 | True | eligible=False |
| weighted_mean | 5 | 10.1666 | 4 / 3 | False | eligible=False |

모든 실험의 실제 공개 기능은 꺼져 있다. N/편차/가중치/평균 방식의 운영값은 미정이다.
계정 수는 서로 다른 실제 사람 수를 보장하지 않는다. 실제 데이터와 악용 시나리오 검증이 더 필요하다.
